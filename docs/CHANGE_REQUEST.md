# VECTR Change Request Template

```text
FEATURE / CHANGE:
[what should be added or changed]

WHY:
[user/business reason]

CURRENT BEHAVIOR:
[what VECTR does today]

EXPECTED BEHAVIOR:
[desired flow]

AFFECTED USERS:
platform owner / org admin / candidate / proctor

PRIORITY:
reliability / performance / UX / security / feature

CONSTRAINTS:
- inspect current Repomix context first
- reuse existing architecture when possible
- no new dependency unless it earns its cost
- no temporary admin passwords
- preserve tenant isolation
- preserve single-device enforcement
- migration only if schema/RPC/index really changes
- performance > decorative visual effects on candidate pages
- output as copy-paste patch/ZIP
- include verification and rollback notes
```
