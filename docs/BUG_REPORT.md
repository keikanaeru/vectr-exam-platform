# VECTR Bug Report Template

Copy this block into ChatGPT when reporting a bug.

```text
BUG:
[short description]

PAGE / ROUTE:
[e.g. /admin/platform]

ACTION:
[exact action performed]

EXPECTED:
[what should happen]

ACTUAL:
[what happened]

REPRODUCIBLE:
always / sometimes / once

ERROR:
[paste terminal/browser/log error]

EVIDENCE:
[screenshot, Vercel log, Supabase log, Lighthouse result]

CONTEXT:
latest repomix-output.xml attached: yes/no

CONSTRAINTS:
- deep scan root cause first
- do not edit GitHub
- do not change database unless required
- do not weaken security
- preserve R8.2/R8.3 behavior
- if code changes are needed, provide copy-paste patch/ZIP
- state exactly what must PASS after applying
```
